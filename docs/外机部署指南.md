## 第一步：安装 Docker

### Windows

1. 下载 Docker Desktop：https://www.docker.com/products/docker-desktop/
2. 安装时勾选 **Use WSL 2**
3. 安装完成后重启电脑
4. 打开 Docker Desktop，等待鲸鱼图标变绿

### macOS

1. 下载 Docker Desktop：https://www.docker.com/products/docker-desktop/
2. 安装并启动
3. 等待状态栏图标显示运行中

### Linux (Ubuntu/Debian)

```bash
# 安装 Docker
sudo apt update
sudo apt install -y docker.io docker-compose-plugin

# 启动 Docker
sudo systemctl enable docker
sudo systemctl start docker

# 添加用户到 docker 组（避免每次用 sudo）
sudo usermod -aG docker $USER
newgrp docker
```

### 验证安装

```bash
docker --version
docker compose version
docker info
```

## 第三步：配置环境变量

```bash
# 进入 deploy 目录
cd deploy

# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件（可选）
# 如需配置 AI 问答功能，修改以下内容：
# LLM_API_KEY=sk-xxxxx      # DeepSeek API Key
# LLM_MODEL=deepseek-chat   # 模型名称
```

**默认配置说明：**
- MySQL：root 密码 `knowledgeflow`，端口 `3307`
- Redis：端口 `6380`
- MinIO：用户名 `minioadmin`，密码 `minioadmin`
- Qdrant：默认配置，端口 `6333`

## 第四步：启动服务

```bash
# 确保在 deploy 目录下
cd deploy

# 构建并启动所有服务（首次需要 5-15 分钟）
docker compose up -d --build

# 查看服务状态
docker compose ps
```

## 常见问题排查

### 问题 1：端口被占用

```bash
# 检查端口占用
netstat -ano | findstr :3307
netstat -ano | findstr :8080

# 修改 docker-compose.yml 中的端口映射
# 例如：3307:3306 改为 3308:3306
```

### 问题 2：镜像拉取失败

```bash
# 配置 Docker 国内镜像加速
# Windows: Docker Desktop -> Settings -> Resources -> Docker Hub mirror

# 手动拉取常用镜像
docker pull mysql:8
docker pull redis:7-alpine
docker pull qdrant/qdrant
docker pull minio/minio
```

### 问题 3：服务启动失败

```bash
# 查看日志
docker compose logs -f backend
docker compose logs -f ai-service
docker compose logs -f mysql

# 重启服务
docker compose restart
```

### 问题 4：AI 问答无响应

```bash
# 检查 API Key 配置
docker exec knowledgeflow-ai env | grep LLM

# 测试 AI 服务健康
curl http://localhost:8000/ai/health
```

## 停止和重置

### 停止服务

```bash
# 停止所有服务（保留数据卷）
docker compose down

# 停止并删除数据卷（慎用！会清空所有数据）
docker compose down -v
```

### 重置系统

```bash
# 完全重置（删除所有数据）
docker compose down -v
docker volume prune -f
docker compose up -d --build
```

## 性能优化建议

### 1. 调整 Docker 内存限制

```
Docker Desktop -> Settings -> Resources -> Memory
建议设置为：6144MB（6GB）及以上（全栈 11 个容器含 JVM，4GB 偏紧）
```

### 2. 生产环境添加内存限制

在 `docker-compose.yml` 中为每个服务添加：

```yaml
services:
  mysql:
    mem_limit: 768m
  redis:
    mem_limit: 128m
  qdrant:
    mem_limit: 1024m
  backend:
    mem_limit: 1536m  # JVM -Xmx1g + 元空间，512m 会 OOMKill
  ai-service:
    mem_limit: 256m
```

### 3. 使用 Linux 服务器

Linux 原生 Docker 性能优于 Docker Desktop：

```bash
# 推荐配置
内存：16GB
磁盘：SSD 100GB
CPU：8核
```
